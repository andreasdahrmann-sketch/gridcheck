# GridCheck Pre-Code-Check
# =========================
# Vor JEDER Code-Ausgabe diese Checkliste durchgehen:

## 1. TYPE-CHECK
- [ ] types/index.ts gelesen?
- [ ] Alle verwendeten Properties existieren im Interface?
- [ ] Keine neuen Properties ohne Type-Update?

## 2. DEPENDENCY-CHECK  
- [ ] Welche Dateien importiert die neue Datei?
- [ ] Existieren alle Imports?
- [ ] Sind die Export-Namen korrekt?

## 3. POWERSHELL-CHECK
- [ ] Single-Quoted Here-String @'"'"'...'"'"'@?
- [ ] Keine Backtick-Template-Literals?
- [ ] UTF8 ohne BOM?
- [ ] [System.IO.File]::WriteAllText() verwendet?

## 4. JSX-CHECK
- [ ] Alle Tags geschlossen?
- [ ] Ein Root-Element pro Return?
- [ ] className statt class?
- [ ] String-Concatenation statt Template Literals?

## 5. POST-CHECK
- [ ] npx tsc --noEmit
- [ ] npm run build (bei Meilenstein)
- [ ] Backup erstellt?
