Native Shell

GridCheck wartet auf die PWA-URL.

Diese Fallback-Seite ist nur das lokale Startpaket fuer den Capacitor-Shell. Fuer reale Android- oder iOS-Builds setze vor npx cap sync die Variable CAPACITOR_SERVER_URL auf eine erreichbare HTTPS-URL der bestehenden Next.js/PWA-Bereitstellung.

Ohne Server-URL bleibt die Web/PWA-Laufbahn unangetastet, und der native Shell startet bewusst nur diese Platzhalterseite statt eine halbfertige App zu laden.
