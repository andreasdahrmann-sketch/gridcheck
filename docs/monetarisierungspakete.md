# Monetarisierungspakete (MVP -> Growth)

## Ziel
Diese Datei konkretisiert die Monetarisierung aus `Ideen.md` in umsetzbare Pakete mit klaren Scope-Grenzen.
Sie dient als Produkt- und Umsetzungsreferenz fuer Sprint-Planung, Vertrieb und Priorisierung.

## Paket 1: Project Developer

- Zielgruppe: Projektierer, EPC, kleinere Entwicklerteams.
- Job-to-be-done: schnelle Vorpruefung, um Sackgassen frueh zu vermeiden.
- Produktumfang (MVP):
  - Standortcheck
  - Netzebenen-Vorschlag
  - Anschlusskandidaten
  - Bedingungsdiagnose
  - PDF-Export
  - einfache Kostenbandbreite
- Nicht enthalten (MVP-Grenze):
  - Portfoliovergleich
  - Vollstaendige Due-Diligence
  - Netzbetreiber-spezifische Intake-Automation
- Preismodell (Rahmen):
  - 499-1.490 EUR/Monat
  - alternativ 99-490 EUR pro Analyse
- Primare Erfolgsmetriken:
  - Time-to-First-Result
  - Conversion von Trial zu Paid
  - Wiederholungsquote pro Projektierer-Team

## Paket 2: Storage / Investment Intelligence

- Zielgruppe: Speicherparkbetreiber, Investoren, Asset Owner.
- Job-to-be-done: Investierbarkeit und Risiko-/Renditeprofil belastbar einschaetzen.
- Produktumfang:
  - alle Features aus Paket 1
  - CAPEX-/Timeline-/Risiko-Modell
  - Szenariorechnungen
  - Portfoliovergleich
  - Management-Report
  - Regionenranking
- Abhaengigkeiten:
  - belastbare Datenquellen-Pipeline (MaStR/SMARD/DWD + spaeter weitere)
  - stabile Datenmodell-Tabellen fuer Signale, Wetter, Kostenindizes
- Preismodell (Rahmen):
  - 2.500-10.000 EUR/Monat
  - alternativ 5.000-25.000 EUR pro Projekt-/Portfolioanalyse
- Primare Erfolgsmetriken:
  - Upsell-Quote aus Paket 1
  - durchschnittlicher Vertragswert
  - Anzahl Portfolioauswertungen pro Kunde

## Paket 3: Grid Operator Suite

- Zielgruppe: Netzbetreiber.
- Job-to-be-done: standardisierte Vorpruefung, Priorisierung und revisionssichere Fallakte.
- Produktumfang:
  - Intake-Management
  - automatische Vorpruefung
  - Priorisierung
  - Fallakte
  - Audit-Trail
  - Rollen/Rechte
  - Schnittstellen
  - internes Dashboard
- Nicht enthalten (MVP-Grenze):
  - verbindliche Netzanschlusszusage
  - garantierte Kapazitaetsauskunft ohne verifizierte DSO-Daten
- Preismodell (Rahmen):
  - Setup 15.000-100.000 EUR
  - Lizenz 30.000-200.000 EUR+ pro Jahr
  - Support/SLA zusaetzlich
- Primare Erfolgsmetriken:
  - reduzierte Bearbeitungszeit je Fall
  - weniger Rueckfragen im Intake
  - Nachvollziehbarkeit in Audit- und Pruefprozessen

## Paket-Mapping zu Roadmap

- Sprint 1 (laufend): Paket 1 als kaufbares Kernprodukt abschliessen.
- Sprint 2 (VNB): Fundament fuer Paket 3 legen (VNB-Route, Auflagen, Pruefprotokoll).
- Sprint 3 (Invest): Fundament fuer Paket 2 legen (ROI, Curtailment, Szenario-/Portfoliologik).
- Sprint 4-5: Paket-Vertiefung durch KI-Feedback und Multi-VNB-Vergleich.

## Go-to-Market Reihenfolge

1. Paket 1 stabilisieren und produktisieren.
2. Paket 2 als Upsell fuer bestehende Projektierer-/Speicherkunden aufbauen.
3. Paket 3 mit laengerem Sales-Cycle parallel als Enterprise-Track entwickeln.

## Offene Entscheidungen

- Finale Preisgrenzen pro Segment und Region.
- Trial-/Freemium-Strategie fuer Paket 1.
- Vertragsmodell fuer Paket 3 (pro Netzgebiet, pro Nutzer, pro Fallvolumen).
- SLA-Stufen und Supportpakete.
